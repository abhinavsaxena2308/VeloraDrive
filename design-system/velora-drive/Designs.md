# 🎯 CORE UI PRINCIPLES

# 1. VISUAL HIERARCHY

Always guide user attention.

Use:

* font size
* spacing
* contrast
* color emphasis
* positioning

Priority flow:

1. Main CTA
2. Main heading
3. Important content
4. Secondary information

Never make everything visually loud.

---

# 2. WHITESPACE

Whitespace creates premium feel.

Rules:

* large section spacing
* breathable layouts
* avoid clutter
* increase readability

Premium websites use MORE spacing.

Not less.

---

# 3. CONSISTENCY

Maintain:

* consistent paddings
* consistent button styles
* consistent typography
* consistent shadows
* consistent border radius
* consistent animation timing

Create reusable design systems.

---

# 4. MINIMALISM

Remove unnecessary UI.

Ask:

* does this improve UX?
* does this create clarity?
* is this visually distracting?

Modern premium UI is:

* clean
* intentional
* focused

# 🎨 COLOR SYSTEM

# Luxury Dark Theme

Primary Colors:

* Matte Black → #0B0B0B
* Charcoal → #111111
* Dark Gray → #1A1A1A

Accent Colors:

* Electric Blue → #00BFFF
* Cyan Glow → #00E5FF
* Silver → #C0C0C0

Text:

* White → #FFFFFF
* Secondary Text → rgba(255,255,255,0.7)

---

# 🌈 COLOR USAGE RULES

Use accent colors ONLY for:

* CTA buttons
* active states
* hover states
* focus states
* highlights

Avoid:

* too many bright colors
* rainbow UI
* random gradients

Premium UI uses restrained color usage.

---

# ✍️ TYPOGRAPHY SYSTEM

Recommended Fonts:

* Inter
* Satoshi
* Poppins
* Manrope

---

# TYPOGRAPHY RULES

Headings:

* bold
* large
* tight tracking

Paragraphs:

* readable width
* proper line-height
* muted color

Avoid:

* tiny text
* overly decorative fonts

Use typography hierarchy properly.

Example:

* H1 → 64px
* H2 → 48px
* H3 → 32px
* Body → 16px
* Caption → 14px

---

# 📦 COMPONENT DESIGN SYSTEM

# BUTTONS

Buttons should:

* feel tactile
* have depth
* animate smoothly

Use:

* hover scaling
* glow effects
* gradient accents
* smooth transitions

CTA buttons must visually dominate.

---

# CARDS

Cards should:

* use glassmorphism carefully
* have subtle shadows
* rounded corners
* hover lift effects

Never use:

* flat ugly boxes
* harsh borders

Use:

* blur
* glow
* layered depth

---

# INPUT FIELDS

Modern inputs should:

* animate on focus
* glow subtly
* have proper padding
* clear labels

Avoid:

* outdated forms
* sharp edges
* cramped layouts

---

# 🌀 ANIMATION PRINCIPLES

Animations should:

* support UX
* feel smooth
* feel natural
* never distract

---

# RECOMMENDED ANIMATIONS

Use:

* fade up
* stagger reveal
* parallax
* smooth hover
* magnetic buttons
* page transitions

Avoid:

* excessive bouncing
* random spinning
* flashy effects

---

# ANIMATION TIMING

Recommended:

* 200ms → hover
* 400ms → card transitions
* 600ms → section reveals

Use:

* ease-out
* cubic-bezier
* spring physics

---

# 🧊 GLASSMORPHISM RULES

Use glass effects carefully.

Correct Usage:

* navbar
* floating panels
* booking widgets
* overlays

Use:

* backdrop blur
* transparent backgrounds
* soft borders

Avoid:

* excessive blur everywhere
* unreadable glass panels
